# Asset register

Every third-party asset that ships in the game gets a row here. Required by several licenses and by our
[licensing](licensing.md) policy. Update it when you buy, import, or stop using an asset.

**Shipped as** values: `pack` (encrypted runtime pack), `raw` (CC0 only), `raw+credit` (CC-BY, credited in-game).
